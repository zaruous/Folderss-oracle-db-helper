DB Helper SQL 편집기 SELECT 강조 검수

AvalonEdit 편집기에 주석·문자열·키워드·자료형 색과 증분 강조를 붙인 시험판(도구 › AvalonEdit PoC)과 설정 창의 새 "SQL 편집기" 탭을 Folderss 없이 플러그인 단독 호스트로 띄워 확인하고 캡처했습니다. 본 SQL 탭 편집기는 아직 바꾸지 않았습니다.

대상: 플러그인 zaruous.folderss-db-helper 1.9.0 (main + PR #25) 호스트: 숨은 데스크톱 · 소프트웨어 렌더링 시험: tests/MyPlugin.UiTests/EditorPocHeadlessTests

검수 방법: 플러그인 단독 호스트

시험 호스트가 publish한 플러그인 zip을 Folderss와 같은 로드 컨텍스트(PluginLoadContext, .deps.json)로 불러 CreateView()를 창에 담습니다. 창은 사용자 화면이 아닌 숨은 데스크톱에 뜨고, 사람이 쓰는 순서대로 메뉴를 눌러 PoC 창을 엽니다. 테마는 Folderss의 색 사전 7종과 컨트롤 스타일 사본을 씁니다.

키워드 색: DBMS별 목록

문장 나누기와 같은 토크나이저가 낸 낱말 토큰이 그 DBMS의 키워드 목록에 있으면 키워드로 칠합니다. 문장·절·조건·테이블 정의·트랜잭션·블록 키워드와 자료형이 들어가고, 함수 이름(COUNT·NVL)은 넣지 않았습니다.

SELECT FROM WHERE'문자열'-- 주석보통 글자: 테이블·열 이름, 따옴표 식별자

확인한 함정

문자열 'SELECT FROM', 주석 안의 SELECT, 따옴표 식별자 "Select"·[select], 앞에 .·:·@가 붙은 t.date·:from·@from, select_flag·fromage 같은 낱말은 키워드로 칠하지 않습니다. 시험은 화면에 그려진 글자의 실제 색을 위치마다 읽어 비교했습니다.

같은 글, 다른 규칙

계획서의 D1 경계 사례(힌트, '', q'[…]', 여러 줄 문자열, 이모지, PL/SQL 블록, PostgreSQL·SQL Server 전용 줄)를 세 규칙으로 칠했습니다. 탭 대상 DB를 바꾸면 처음부터 다시 칠합니다.

설정: SQL 편집기 탭

Folderss 설정에는 편집기 줄 간격 같은 항목이 없어서 플러그인 설정 창에 "SQL 편집기" 탭을 두었습니다. 칸을 고치면 아래 미리 보기에 바로 보이고, [저장]하면 열려 있는 편집기가 바로 따릅니다. 잘못 적은 값은 저장 실패로 알립니다.

  • 표시: 줄 간격(글꼴 기본 15px, 16~32px — 19px는 지금 SQL 탭과 같음), 칠하지 않을 긴 줄 기준(기본 20,000자, 1,000~1,000,000).
  • 구문 강조: 키워드·자료형·문자열·주석마다 칠함, 색(비우면 테마 색), 굵게, 기울임. 지금 테마 바탕과 비교한 명암비를 옆에 보이고 4.5:1 미만이면 "읽기 어려움"으로 표시합니다.
  • 키워드 대상: 더 칠할 낱말(예: NVL DECODE)과 칠하지 않을 낱말(예: 열 이름과 겹치는 LEVEL TEXT). 세 DBMS에 모두 적용됩니다. 자료형은 이번에 키워드와 따로 떼어 따로 꾸밀 수 있게 했습니다.

테마 7종

강조색은 테마 색에서 계산합니다. 주석은 보조 글자색이지만 본문과 너무 비슷하면(Nord·Catppuccin·Dracula) 바탕 쪽으로 옮기고, 문자열은 밝은 테마에서 진한 주황, 키워드는 테마 강조색을 쓰되 대비가 모자라면 바탕에서 멀어지게 조정합니다. 테마를 바꾸면 편집기를 바로 다시 칠합니다.

결정과 남은 것

  • 키 동작 (결정): 여러 줄 선택 Tab·Shift+Tab, Enter 들여쓰기, Home, 선택 없는 Ctrl+C·X는 AvalonEdit 동작을 씁니다. Ctrl+D(줄 삭제)는 껐고 Insert는 지금처럼 겹쳐쓰기를 전환합니다.
  • 줄 간격 (결정): 설정 탭의 선택 항목으로 두었습니다. 기본은 글꼴 기본(15px)이고 19px를 고르면 지금 SQL 탭과 같습니다. AvalonEdit에 줄 간격 속성이 없어 같은 글꼴을 가리키는 합성 글꼴의 줄 간격으로 정합니다.
  • 강조 대상과 모양 (결정): 설정 탭에서 관리합니다. 자료형은 키워드와 따로 떼었고 기본은 키워드와 같은 색입니다. 함수 이름은 "더 칠할 낱말"로 더합니다.
  • 긴 줄 (결정): 칠하지 않을 기준은 기본 20,000자로 두고 설정 탭에서 바꿉니다. 한 줄 1MB는 AvalonEdit·TextBox 모두 입력이 느립니다(편집기 한계).
  • PostgreSQL 함수 본문 (보류): $$ … $$ 안은 문자열색입니다. 본문 안도 SQL로 칠하려면 달러 따옴표 안을 한 번 더 훑어야 합니다.
  • 한글 IME (남음): 사람이 Folderss에서 확인해야 합니다. 이것까지 문제없으면 SQL 탭 편집기 교체(3단계)를 시작합니다.
